COMPUTED ZOOM

step = exp(−pixelDelta × sensitivity). Each wheel event multiplies the current zoom by that step. Both objects zoom around their center and use the same 0.2–4× limits.

No rotation or native pinch start/end is available from wheel. “Idle” is inferred after 160 ms without a pinch event. ctrlKey also matches a real Control key plus wheel; it cannot identify the physical input by itself.

Wheel event reference ↗

Pixel deltas are used directly. Line deltas use a demo convention of 16 px per line; page deltas use the surface height. Sensitivity is adjustable, so this is not a claim of identical browser zoom speed.
